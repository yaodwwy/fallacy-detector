# 用户输入模板 (User Input Template)

当你希望 AI 调用《逻辑谬误与诡辩甄别 Skill》审计某段聊天记录、会议发言或争论内容时，可以直接复制以下模板发给 AI：

```markdown
请调用【逻辑谬误与诡辩甄别技能 (fallacy-detector)】，对以下内容进行深度逻辑审计：

### 1. 对话背景与语境 (Context)
- **发生场景**：[例如：公司战略复盘会 / 微信工作群 / 客户商业谈判 / 社交媒体公关回应]
- **涉及角色与关系**：[例如：A是业务线负责人，B是财务总监 / 甲是消费者，乙是客服]
- **当前核心争端**：[例如：是否向连续亏损的项目追加预算 / 出现产品故障后责任归属]

### 2. 原始记录/发言内容 (Transcript / Statements)
"""
[在此处直接粘贴原始聊天记录、会议录音转文字或对方的原话]
例如：
A: “这个方案是上周硅谷最新发布的架构，绝对是业界最领先的！”
B: “可是我们目前的业务体量需要这么复杂的架构吗？”
A: “你怎么总是质疑团队的创新精神？要是按照你这种保守思路，公司早晚被行业淘汰！”
"""

### 3. 我的核心诉求 (Goal)
- [ ] 揪出对方所有的逻辑漏洞与诡辩话术（标明谬误名称与编号）
- [ ] 剖析为什么对方的推导不成立（指出偷换概念或逻辑跳跃）
- [ ] 给出高情商、一针见血的反驳话术与苏格拉底式追问（我想体面破局）
- [ ] 自查：评估我方在对话中是否存在逻辑不严谨的地方
```
